## Webpage

The deployed webpage is available at:

https://ai-clinical-platform.duckdns.org/

## Login Notes

Use the admin account to access admin-related features.

Use any provider account to access provider-related features.

## Templates Management

If we are generating a note template that has been deactivated/deleted, the page will be refreshed and no AI content will be generated.

If we are manipulating a note template that has been deleted as the admin, the page will be refreshed and no action will be taken.
